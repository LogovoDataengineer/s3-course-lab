# Учебный стенд курса «S3 для дата-инженера»

Репозиторий-шаблон для GitHub Codespaces. Создайте из него свой репозиторий кнопкой **Use this template**, затем Codespace кнопкой **Code → Codespaces → Create codespace on main**. Подробно по шагам — урок L01 курса.

| Команда | Что делает |
|---|---|
| `make up` | собирает MinIO (первый раз 10–20 минут), запускает стенд, создаёт учебных пользователей |
| `make ps` | показывает состояние контейнеров |
| `make down` | останавливает стенд, данные сохраняются |
| `make reset CONFIRM=yes` | удаляет стенд вместе со всеми бакетами |

Консоль MinIO: порт 19001 на вкладке **PORTS**. Вход: `courseadmin` / `local-admin-123456`. S3 API: `http://localhost:19000`.

Логины и пароли учебные и годятся только для этого стенда: порты открыты лишь внутри вашего Codespace.
